# NGODING YUK!

### Interactive Coding Learning Platform

[![Live Demo](https://img.shields.io/badge/Live%20Demo-GitHub%20Pages-2ea44f?style=for-the-badge)](https://icyHollow2627.github.io/NgodingYuk/)
[![Repository](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github)](https://github.com/icyHollow2627/NgodingYuk)

**Akses website:** https://rafi-ramadhan-999.github.io/NgodingYuk/

Ngoding Yuk! adalah platform pembelajaran pemrograman berbasis web yang dirancang untuk membantu pemula mempelajari berbagai bahasa pemrograman melalui materi bertingkat, editor interaktif, latihan, dan kuis.

Proyek ini berawal dari ide dan konsep **Rafi Ramadhan**, dengan tujuan menghadirkan pengalaman belajar coding yang mudah diakses, interaktif, dan menyenangkan.

## Features

- **9 Bahasa Pemrograman:** HTML, CSS, JavaScript, Python, C, C++, SQL, Kotlin, dan C#.
- **Materi Bertingkat:** Pembelajaran dari level Dasar, Menengah, hingga Lanjut.
- **Interactive Code Editor:** Editor kode dengan fitur menjalankan kode dan melihat hasil latihan.
- **Latihan & Tantangan:** Pemeriksaan otomatis untuk membantu pengguna mengevaluasi jawaban.
- **Quiz System:** Kuis acak berdasarkan bahasa pemrograman dan tingkat pembelajaran.
- **Learning Progress:** Pemantauan progres belajar setiap pengguna.
- **XP & Level System:** Sistem pengalaman dan level pembelajaran.
- **Achievement Badges:** Lencana berdasarkan pencapaian pengguna.
- **Leaderboard:** Antarmuka papan peringkat.
- **Responsive Interface:** Tampilan yang menyesuaikan perangkat desktop dan mobile.
- **Dark Mode:** Dukungan tema gelap berdasarkan preferensi sistem.
- **Learning Motivation:** Fun facts dan kutipan motivasi.

## Important Notes

- Editor dan runner menggunakan pendekatan simulasi untuk beberapa bahasa pemrograman. Simulasi memiliki keterbatasan dan tidak sepenuhnya menggantikan compiler atau runtime asli.
- Progres belajar disimpan menggunakan LocalStorage pada browser masing-masing pengguna.
- Fitur leaderboard bersama membutuhkan dukungan backend/runtime yang sesuai. Tanpa dukungan tersebut, papan peringkat tidak berfungsi sebagai leaderboard global lintas pengguna.

NGODING YUK!

Interactive Coding Learning Platform

Ngoding Yuk! adalah platform pembelajaran pemrograman berbasis web yang dirancang untuk membantu pemula mempelajari berbagai bahasa pemrograman melalui materi bertingkat, editor interaktif, latihan, dan kuis.

Proyek ini berawal dari ide dan konsep Rafi Ramadhan, dengan tujuan menghadirkan pengalaman belajar coding yang mudah diakses, interaktif, dan menyenangkan.

---

Features

- 9 Programming Languages: HTML, CSS, JavaScript, Python, C, C++, SQL, Kotlin, dan C#.
- Structured Learning: Materi pembelajaran dengan tiga tingkatan: Dasar, Menengah, dan Lanjut.
- Interactive Code Editor: Editor kode dengan fitur menjalankan kode dan melihat hasilnya.
- Practice & Challenges: Latihan pemrograman dengan pemeriksaan otomatis.
- Quiz System: Kuis acak berdasarkan bahasa pemrograman dan tingkat pembelajaran.
- Learning Progress: Pemantauan perkembangan belajar pengguna.
- XP & Level System: Sistem pengalaman dan level pembelajaran.
- Achievement Badges: Lencana berdasarkan pencapaian pengguna.
- Leaderboard: Antarmuka papan peringkat.
- Responsive Interface: Tampilan yang menyesuaikan perangkat desktop dan mobile.
- Dark Mode: Dukungan tema gelap berdasarkan preferensi sistem.
- Learning Motivation: Fun facts dan kutipan motivasi untuk mendukung proses belajar.

Important Notes

Editor dan runner dalam proyek ini menggunakan pendekatan simulasi untuk beberapa bahasa pemrograman. Simulasi tersebut memiliki keterbatasan dan tidak sepenuhnya menggantikan compiler atau runtime asli.

Progres belajar disimpan menggunakan LocalStorage pada browser masing-masing pengguna. Fitur leaderboard bersama membutuhkan dukungan backend/runtime yang sesuai.
